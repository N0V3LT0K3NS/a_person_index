# Changelog

All notable changes to A Person Index are documented here.

## v0.1.0 - 2026-04-13

First public release of A Person Index as a shareable Git-native substrate.

Included in this release:

- canonical instrument-centered corpus with 15 seeded framework records
- house synthesis layer with motifs, construct mappings, and interaction hypotheses
- technique library and first index programs, including `ILENS`, `Human Model Card`, `Translation Memo`, and `Paradox Finder`
- curated runtime packs and machine-readable pack grammar
- research contribution models, promotion policy, and result atom schema
- generated JSON exports and static docs site
- read-only MCP adapter over the Python query surface
- companion Codex skill vendored into the repo
- tested client paths for Claude Code and Hermes
- GitHub governance surfaces, CI, and Netlify deployment workflow

Release stance:

- ready for canonical curation
- ready for downstream agent and runtime consumption through CLI, generated JSON, and read-only MCP
- not the person-level inference engine
- not the hosted research operations layer
- not yet a hosted remote MCP service

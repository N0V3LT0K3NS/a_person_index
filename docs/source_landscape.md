# Source Landscape

This document maps the external source surfaces currently worth using for A Person Index expansion work.

It is a scouting and sourcing guide, not a license to treat every linked site as equally authoritative.

## How to read this

Each source surface should be used for one or more of:

- discovery
- canonical framework description
- independent critique
- implementation context
- candidate-framework scouting

Do not promote a source surface into a stronger authority class than it deserves.

## SimilarMinds

Role:

- discovery of internet-native and folk frameworks
- ecosystem context for site-native systems
- implementation context for widely circulated pop-framework variants

Use for:

- R-Drive
- True Colors or similar workplace-pop cleanup work
- discovery of recurring internet-circulating framework seams

Do not use it alone for:

- strong empirical claims
- evidence-profile upgrades

References:

- [SimilarMinds home](https://similarminds.com/index.html)
- [R-Drive info](https://similarminds.com/rdrive_nfo.html)

## Open Source Psychometrics Project

Role:

- open implementation and open-data ecosystem context
- discovery surface for adjacent open measures
- implementation reference for open forms of known frameworks

Use for:

- source enrichment of existing framework records
- open-instrument ecosystem notes
- discovery of candidate follow-on frameworks that still need primary sourcing

Do not use it alone for:

- canonical claims about a framework whose primary source lives elsewhere

References:

- [OpenPsychometrics about](https://openpsychometrics.org/about/)
- [Open Jungian Type Scales](https://openpsychometrics.org/tests/OJTS/)
- [OpenPsychometrics tests index](https://openpsychometrics.org/tests/)

## Creativity and ideation measures

This family needs better separation than the phrase "creativity test" usually gets.

The repo should treat at least three adjacent seams separately:

1. divergent ideation
2. associative or convergent creative linkage
3. trait-level openness, abstraction, and novelty appetite

### Divergent Association Task

Use as:

- the primary modern anchor for a divergent-association measure
- a bridge into creativity-task family expansion

References:

- [DAT home](https://www.datcreativity.com/)
- [DAT about](https://www.datcreativity.com/about)
- [DAT PNAS paper](https://doi.org/10.1073/pnas.2022340118)

### Remote Associates lineage

The user phrase "creative association test" is ambiguous. Until a narrower source is specified, treat it as a likely pointer to the Remote Associates lineage or another associative-creativity task.

Use as:

- the primary starting point for associative-creativity task inclusion

Reference:

- [Mednick, 1962, "The associative basis of the creative process"](https://doi.org/10.1037/h0048850)

### Alternative Uses lineage

Use as:

- the primary starting point for classic divergent-thinking task inclusion
- a way to keep creativity-task scoring distinct from broad personality claims

References:

- [Guilford, *The Nature of Human Intelligence*](https://archive.org/details/natureofhumanint00guil)
- [Wallach and Kogan line via the Journal of Creative Behavior alternate uses task paper](https://doi.org/10.1002/j.2162-6057.1967.tb00002.x)

## Recommended expansion order

1. strengthen sources and internal linking across the seeded corpus
2. add R-Drive because it is already a real missing consumer input
3. add Political Compass to broaden worldview coverage
4. add the next creativity tasks as separate bounded PRs, not one diffuse family dump
5. densify crosswalks and interaction hypotheses after the source objects exist

## Operating rule

Use these source surfaces as jump-off points.

For every new framework record:

- identify the strongest available primary source
- identify at least one independent or critical source when the framework claims empirical standing
- explain the source role in the resource notes
- encode the framework conservatively enough that downstream agents can reason over it without mistaking familiarity for validity

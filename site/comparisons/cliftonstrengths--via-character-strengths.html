  • VIA Character Strengths -> CliftonStrengths [same_layer_different_cut / medium / high]

  • Wisdom -> Strategic Thinking [same_layer_different_cut / high / high]

    A strong bi-directional bridge across strengths vocabularies.
  • Humanity -> Relationship Building [loose_overlap / high / high]
    Humanity and Relationship Building both emphasize warmth and connection, though VIA emphasizes ethical character while CliftonStrengths emphasizes relational effectiveness.
    Shared interpersonal emphasis with different normative framing.
  • Courage -> Influencing [loose_overlap / medium / medium]

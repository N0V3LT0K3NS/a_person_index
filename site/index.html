A Person Index

One place for personhood frameworks to finally talk to each other.

A Person Index (API) is a Git-native substrate for storing personhood frameworks faithfully, translating across them through a shared house interlingua, and composing reusable analysis programs that downstream runtimes can call without re-deriving the map by hand.

What it does

Built to archive, translate, compose, and return signal.

The point is not to rank frameworks by legitimacy and stop. The point is to preserve them, dimension them, and make them interoperable without destroying their differences.

Composition Model

Low-tech legos, not magical black boxes.

A Person Index separates atomic operations from composed analyses and then hydrates those analyses into scoped runtime bundles.

1. Techniques

Small reusable operations

Atomic moves such as `Paradox Scan`, `Cross-Framework Translation`, and `Result Atom Decomposition`.

atomicreusablecomparative
2. Index programs

Named composed analyses

Programs such as `Paradox Finder`, `Translation Memo`, `ILENS`, and `Human Model Card` that compose techniques into a stable workflow.

Paradox FinderILENSTranslation Memo
3. Program packs

Scoped runtime bundles

Curated or dynamic packs that attach frameworks, motifs, mappings, interactions, and return contracts to a specific program run.
